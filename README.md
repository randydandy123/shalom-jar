# The Jar

The live scoreboard of The Fermentation Club. `index.html` is the page, `jar.json` is the numbers. The page reads `jar.json` on every open and every five minutes, so changing the file changes the page for everyone. Nothing else runs here.

To update: edit `jar.json`, commit, push. Field list in the-system, `clients/SHALOM/C-core/notion-board.md`, under **The Jar**.
